# LifeOS Pro

**Версия Pro — второй уровень LifeOS.** Возможности, которые превращают персональную систему из «приложения на одном компьютере» в инфраструктуру: доступную откуда угодно и работающую без постоянного участия человека.

## Уровни LifeOS

| Уровень | Что это | Где работает |
|---|---|---|
| **Уровень 1 — Базовая система** | Obsidian + Claude Code на одном компьютере: vault, заметки, проекты, навыки, цели, ритуалы | Один компьютер, локально |
| **Уровень 2 — Pro** | Удалённый доступ, выделенный сервер, агенты и процессы, работающие 24/7 | Выделенный сервер + любой клиент (в т.ч. телефон) |

Уровень 1 — это то, что даёт стартовый комплект. Pro строится **поверх**: базовая система никуда не девается, к ней добавляются продвинутые возможности.

Pro набирается этапами. Каждый этап самостоятелен и даёт законченную возможность — их можно внедрять по одному.

| Этап | Возможность | Статус |
|---|---|---|
| **Этап 1** | [[LifeOS Pro/Удалённый доступ через Telegram\|Удалённый доступ через Telegram]] — управление системой с телефона | Готов |

## Принцип обезличивания

Документация Pro написана на переменных-плейсхолдерах — подставь свои значения. Сквозные плейсхолдеры:

| Плейсхолдер | Что означает |
|---|---|
| `<remote-host>` | Выделенный сервер (SSH-алиас или адрес) |
| `<user>` | Имя пользователя на сервере |
| `<vault-path>` | Путь к vault на сервере |
| `<claude-home>` | Домашняя папка Claude Code (обычно `~/.claude`) |
| `<bot-token>` | Токен Telegram-бота от @BotFather |
| `<owner-id>` | Числовой Telegram user ID владельца |
